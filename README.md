# Auto-Pumps

Автоматическая система управления поливом на ESP32 с веб-интерфейсом.

## Возможности

- Управление 8 каналами полива (помпами/клапанами)
- Веб-интерфейс на библиотеке SettingsGyver (тёмная тема)
- Редактирование имён каналов через веб (кириллица UTF-8)
- Настройка периода полива и длительности (в минутах)
- Ручное включение/выключение каналов
- Отображение статуса на LCD 1602 (кириллица)
- Поддержка NTP (синхронизация времени)
- MQTT интеграция для умного дома
- Энкодер для локального управления

## Железо

- **Плата:** Wemos D1 R32 (ESP32)
- **Дисплей:** LCD 1602 I2C (библиотека LCD_1602_RUS)
- **Энкодер:** GyverEncoder с кнопкой
- **Помпы:** 8 каналов на пинах 13, 14, 25, 26, 27, 32, 33, 2

## Схема подключения

```
ESP32 Wemos D1 R32:
├── LCD 1602 I2C: SDA=21, SCL=22, адрес 0x27
├── Энкодер: CLK=18, DT=19, SW=5
├── Общая помпа: пин 4
└── Каналы: 13, 14, 25, 26, 27, 32, 33, 2
```

## Использование

### Веб-интерфейс
После подключения ESP32 к WiFi откройте браузер:

**Разделы:**
1. **Статус системы** — состояние полива, аптайм, WiFi
2. **Выбор помпы** — выпадающий список с именами каналов
3. **Управление помпой:**
   - Редактирование имени (кириллица поддерживается)
   - Статус (включена/выключена)
   - Кнопки "Включить" / "Выключить"
   - Слайдеры: Пауза (0–1440 мин) и Полив (0–60 мин)
4. **Управление поливом** — кнопка "Остановить всё"

### Локальное управление (энкодер)
- **Крутить:** навигация по меню
- **Клик:** выбор/переключение
- **Удержание:** сохранение в EEPROM

### LCD дисплей
- **Первая строка:** имя канала + время NTP
- **Вторая строка:** режим (ПАУЗА/РАБОТА) + таймер ЧЧ:ММ:СС

## Настройка

### WiFi
В `src/config.h`:
```cpp
#define WIFI_SSID "YourSSID"
#define WIFI_PASS "YourPassword"
```

### MQTT (опционально)
```cpp
#define MQTT_BROKER "192.168.1.100"
#define MQTT_PORT 1883
#define MQTT_USER "user"
#define MQTT_PASS "pass"
```

### Параметры системы
```cpp
#define PUPM_AMOUNT 8        // количество каналов
#define SWITCH_LEVEL 0        // активный уровень реле (0=LOW, 1=HIGH)
#define PARALLEL 0            // 0 - только один канал, 1 - параллельно
#define TIMER_START 1         // перезапуск таймера после полива
#define LCD_BACKL 1           // подсветка LCD
#define BACKL_TOUT 60         // таймаут подсветки (сек)
```

## Хранение данных

- **EEPROM:** таймеры (период/полив) + имена каналов (UTF-8)
- **LittleFS:** база данных SettingsGyver (веб-интерфейс)

## Особенности

- Имена каналов редактируются из веб-интерфейса и сохраняются в EEPROM
- Кириллица UTF-8 корректно отображается на LCD и в вебе
- Синхронизация LCD через флаг (без блокировки веб-запросов)
- Автоматическое переподключение WiFi
